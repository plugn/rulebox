 # сниппет для Google Chrome
  
 IIFE экспортирует в контекст окна window.top объект rulebox со следующими свойствами

1. create() - функция, которая создает прозрачный div с рамкой синего цвета толщиной 1px. Это рулбокс, измеритель, линейка.
    Он добавляется в DOM-дерево как абсолютно позиционированный элемент с z-index 90000, размерами 200 x 50.
    Его поведение следующее: по ховеру во внутренней области элемента его внутренняя заливка с прозрачной меняется на цвет рамки с прозрачностью 50%, если в этом состоянии внутри элемента происходит клик мыши, этот цвет сохраняется и рулбокс переходит в состояние `active`. Если клика не случается, по событию `mouseout` цвет заливки возвращается к прозрачному. 
    
    В состоянии `active` 
    * в нижем правом углу появляется `resizer` - белая кнопка 30x30 с контуром цвета рамки рулбокса, ее центр совпадает с координатами угла. ховер на этой кнопке меняет стиль курсора на resize, а при `mousedown` положение мыши начинает отслеживаться (debounce 30ms), `resizer` меняет свое положение так, чтобы его центр совпадал с координатами мыши,  и менять размер рулбокса так, чтобы его правый нижний угол совпадал с положением `resizer`. по событию `mouseup` отслеживание мыши отключается.
    * при `mouseover` внутри рулбокса стиль курсора меняется на `dragging`. при `mousedown` перемещение мыши отслеживается (debounce 30ms),
    сам рулбокс меняет свое положение так, чтобы его центр совпадал с координатами мыши. по событию `mouseup` отслеживание мыши отключается.

    рулбокс помещается в массив rulebox._items


2. list() - функция, возвращает массив rulebox._items 

3. remove(index) - функция удаляет рулбокс по индексу: ```rulebox._items.splice(index, 1, 0)```
