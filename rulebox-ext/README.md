# Rulebox — расширение Chrome

Измерительная линейка поверх страницы: прозрачный рулбокс с синей (или выбранной)
рамкой, перетаскивание, изменение размера и подпись с текущими размерами.
Расширение — обёртка над тем же движком, что и сниппет `../rulebox.js`.

## Установка (dev mode)

1. Открыть `chrome://extensions`.
2. Включить «Режим разработчика».
3. «Загрузить распакованное расширение» → выбрать каталог `rulebox-ext`.
4. Открыть обычную страницу по `http(s)` — на `chrome://`, Chrome Web Store,
   PDF-просмотрщике и страницах ошибок Chrome запрещает выполнять код расширения.
5. Закрепить иконку Rulebox на панели (кнопка «Расширения» — пазл).

Права: `scripting` (инъекция движка и детектора линий), `activeTab` (доступ
только к вкладке, на которой пользователь вызвал расширение), `storage`
(выбранный цвет и настройки магнита). Магнит новых разрешений не требует:
снимок делается через `chrome.tabs.captureVisibleTab` в рамках `activeTab`.

## Использование

Попап (клик по иконке):

- **Цвет рамки** — 7 радиокнопок палитры плюс «Свой цвет» с системным пипеткой.
  Выбор запоминается.
- **Создать рулбокс** — добавляет один рулбокс в центр видимой области активной
  вкладки. После создания автовыбор переключается на **соседний цвет палитры**
  (синий → красный → зелёный → фиолетовый → оранжевый → чёрный → бирюзовый →
  синий), чтобы рулбоксы различались. Произвольный «свой» цвет ротация не трогает.
- **Удалить последний / Удалить все** — работают с рулбоксами активной вкладки;
  недоступны, когда рулбоксов нет.
- **Автообновление при скролле/зуме** — см. раздел «Авто-обновление границ».

Хоткей `Alt+Shift+R` (меняется на `chrome://extensions/shortcuts`) создаёт
рулбокс с текущим цветом без открытия попапа. Комбинация читается из того же
хранилища, поэтому цвет тоже чередуется.

Бейдж на иконке показывает количество рулбоксов на вкладке.

## Магнит

Блок «Магнит» в попапе включает прилипание к контрастным линиям макета:

- Тумблер «Прилипание к контрастным линиям» делает снимок текущего вида
  вкладки (`chrome.tabs.captureVisibleTab`, хватает уже выданного `activeTab`),
  находит в нём длинные вертикальные и горизонтальные границы и передаёт их
  движку как направляющие.
- При перетаскивании рулбокса и при ресайзе ближайшая грань прилипает к линии,
  если до неё не больше «Порога» (2–20 px, по умолчанию 6). В момент
  срабатывания поверх страницы видна красная направляющая; после `mouseup`
  она скрывается.
- Собственные рулбоксы исключаются из карты линий (их прямоугольники
  маскируются), поэтому края рулбоксов не притягивают сами себя.
- Линией считается не только сплошная граница, но и «пунктирная»: несколько
  выровненных коротких отрезков (рамки полей ввода, чекбоксы в столбик).
  Короткие штрихи (пересечения линий, антиалиасинг) отбрасываются, пороги
  `minRun`, `minSupport`, `minSegments`, `minAverageRun` задаются в начале
  `lib/edges.js`.
- Снимок статичный: после прокрутки, зума или изменения макета нажмите
  «Обновить снимок». Выключение тумблера очищает направляющие.

Ограничения: `captureVisibleTab` отдаёт только видимую область и не чаще двух
раз в секунду; тонкие линии при сильном уменьшении макета размываются
антиалиасингом и могут не находиться — тогда увеличьте масштаб или поднимите
порог. Декодирование снимка и поиск линий выполняются в MAIN world страницы
(`lib/edges.js`), чтобы не зависеть от отсутствия DOM в service worker.

## Авто-обновление границ

Тумблер «Автообновление при скролле/зуме» держит карту линий актуальной:

- в страницу внедряется `lib/activity.js` (ISOLATED world); он слушает всё, что
  меняет соответствие «экран ↔ контент»: `scroll`/`scrollend` (включая
  вложенные скроллеры), `wheel` (в том числе ctrl+wheel), panning с зажатой
  кнопкой, `touchmove`, `Ctrl/Cmd +/-/0`, pinch через `visualViewport`, смену
  `devicePixelRatio` (зум из меню браузера), `resize`, `orientationchange`,
  `fullscreenchange`;
- события внутри рулбоксов и во время их перетаскивания/ресайза игнорируются
  (движок помечает жест атрибутом `data-rulebox-gesture`);
- после 3 секунд тишины service worker пересчитывает карту. Минимальный
  интервал между пересчётами — 5 секунд, более частые запросы откладываются и
  схлопываются;
- на время пересчёта направляющие очищаются (старые уже невалидны) и магнит
  не прилипает до готовности новой карты;
- индикация на иконке работает и для ручного «Обновить снимок», и для
  авто-пересчёта: пока идёт пересчёт, текст бейджа — `…`, фон красный (текст
  нужен, иначе Chrome прячет бейдж, когда рулбоксов ещё нет), по завершении
  возвращается число рулбоксов; при ошибке — красный фон и `!`. Сообщение об
  ошибке видно в статусе попапа.
- при перезагрузке страницы бейдж сбрасывается: движок и слушатель активности
  исчезают вместе с DOM.

Ограничение: после перезагрузки страницы внедрённый слушатель исчезает
(без `host_permissions` переинъекция на все вкладки невозможна) — режим
возобновляется при следующем включении из попапа.

Движок внедряется один раз за жизнь страницы. После перезагрузки вкладки
рулбоксы исчезают вместе с DOM — нажмите «Создать» снова (фоновой инъекции на
все сайты намеренно нет: не нужны права `<all_urls>` и лишняя работа на каждой
странице).

## API в консоли страницы

Движок живёт в MAIN world, поэтому `window.rulebox` доступен в DevTools:

```js
rulebox.create();            // рулбокс цветом по умолчанию
rulebox.create('#ff0000');   // рулбокс с указанным цветом рамки
rulebox.list();              // массив созданных рулбоксов
rulebox.remove(0);           // удалить рулбокс по индексу

// Направляющие магнита в клиентских координатах вьюпорта:
rulebox.setGuides([120, 640], [80], 6);
rulebox.clearGuides();
```

## Поведение рулбокса

- 200 × 50, `position: absolute`, `z-index: 90000`, рамка 1px.
- Ховер — заливка цветом рамки с прозрачностью 50 %, уход мыши возвращает
  прозрачность. Клик внутри — состояние `active`: заливка сохраняется, в правом
  нижнем углу появляется resizer 18 × 18.
- В `active`: перетаскивание за тело (курсор `move`) центрирует рулбокс на мыши,
  перетаскивание за resizer меняет размер, минимальный размер 20 × 20.
  Отслеживание мыши — с throttling 30 мс.
- Resizer всегда находится в том углу, который тянет пользователь: если провести
  мышью через противоположный угол, рулбокс переворачивается и растёт в другую
  сторону (например, влево-вверх), ручка остаётся под курсором, а закреплённый
  угол — неподвижным. Курсор ручки: `nwse-resize` на диагональных углах и
  `nesw-resize` при смешанном перевороте (нижний левый / верхний правый).
- Размер при ресайзе не ограничен границами окна: рулбокс может выходить за
  вьюпорт, координаты при этом могут уходить в отрицательные значения.
- Внизу по центру — подпись с актуальным размером (`200 × 50`): цвет рамки, в
  `active` — белый.
- Клик вне всех рулбоксов деактивирует их все.
- У активного рулбокса в каждом углу есть невидимая зона 30 × 30 (или половина
  ребра, если ребро короче 60 px). Курсор в зоне — как у ручки ресайза. Нажатие
  в зоне переключает ручку в этот угол и сразу позволяет тянуть; клик без
  движения просто оставляет ручку в выбранном углу.
- Активированный рулбокс получает фокус; <kbd>Backspace</kbd> (или <kbd>Delete</kbd>)
  удаляет его — как если бы вызвали `rulebox.remove(index)`. В полях ввода
  страницы клавиша работает как обычно: обработчик висит на самом рулбоксе.
- Стрелки сдвигают сфокусированный рулбокс на 1 px, <kbd>Shift</kbd>+стрелки —
  на 10 px.

## Структура

```
rulebox-ext/
├── manifest.json         манифест MV3 (permissions, action, commands)
├── background.js         service worker: инъекция движка в MAIN world,
│                         команды попапа, хоткей, бейдж, ротация цвета
├── lib/
│   ├── rulebox.js        движок (IIFE → window.top.rulebox)
│   ├── palette.js        палитра и правило «соседнего цвета»
│   ├── edges.js          поиск контрастных линий для магнита
│   └── activity.js       слушатель скролла/зума для авто-пересчёта
├── popup.html/css/js     UI: радиогруппа цветов, кнопки, счётчик
├── icons/                16/32/48/128
├── tools/make-icons.py   генерация иконок (Pillow)
└── README.md
```

## Разработка

- После правок: «Обновить» на `chrome://extensions`, затем перезагрузить вкладку.
- Логи service worker: `chrome://extensions` → «Проверка видов» → «service worker».
- Внешний вид и поведение рулбокса настраиваются константами в начале
  `lib/rulebox.js`: `BOX_WIDTH`, `BOX_HEIGHT`, `RESIZER_SIZE`, `CORNER_ZONE`,
  `MIN_SIZE`, `THROTTLE_MS`, `LABEL_FONT_SIZE`, `LABEL_PADDING_BOTTOM`,
  `BORDER_COLOR`, `FILL_COLOR`.
- Палитра и порядок ротации — `lib/palette.js`.
- Пороги детектора линий — `RULEBOX_EDGE_DEFAULTS` в `lib/edges.js`.
- Авто-режим: дебаунс активности — `debounceMs` в `lib/activity.js`
  (по умолчанию 3000), минимальный интервал пересчёта — `AUTO_MIN_INTERVAL`
  в `background.js` (по умолчанию 5000).
- Регенерация иконок: `python3 tools/make-icons.py` (нужен Pillow).
